Solution Approach:
The problem can be modeled as a recurrence relation:
f(n) = f(n-1) + f(n-2) + f(n-5)
Base cases:
f(n) = 0 for n < 0
f(0) = 1

Problem 2. (70%)

Problem Statement:
Optimize an N-body simulation code (nbody.py) to run significantly faster (target: < 30 seconds).

Optimization Strategy:
I implemented four versions of the code, addressing specific areas of improvement as requested.

1. nbody_1.py: Reduced function call overhead.
   - I inlined the helper functions (compute_deltas, compute_b, compute_mag, update_vs, update_rs, compute_energy) directly into the main `advance` function.
   - This removes the overhead of pushing/popping stack frames for millions of small function calls.

2. nbody_2.py: Alternatives to membership testing.
   - The original code used a list `seenit` and checked `if body2 in seenit` inside a nested loop, which is O(N) inside O(N^2), making it inefficient.
   - I replaced this with an index-based double loop `for i in range(n): for j in range(i+1, n):`, which ensures each pair is visited exactly once without any list lookups.

3. nbody_3.py: Using local variables.
   - The original code accessed the global dictionary `BODIES` repeatedly inside the inner loops.
   - In Python, accessing global variables is slower than accessing local variables. I created a local list `bodies = list(BODIES.values())` and passed it to the functions.
   - This version proved to be the fastest optimization.

4. nbody_4.py: Using data aggregation.
   - I flattened the data structure into single lists for positions (r), velocities (v), and masses (m) to avoid the overhead of unpacking tuples.
   - However, in pure Python, the overhead of list indexing and lack of vectorization (unlike NumPy) meant this approach was slightly slower than `nbody_3`.

Final Optimization (nbody_opt.py):
The final version incorporates the most effective optimizations:
- It uses the local variable strategy from `nbody_3.py`.
- It uses the optimized loop structure from `nbody_2.py`.
- It keeps the code clean and readable while maximizing Python's interpreter efficiency.

Speedup Analysis:
Original Time (approx, 100 loops):  29.90 seconds
Optimized Time (approx, 100 loops):  10.71 seconds
Speedup Factor: 2.79x
